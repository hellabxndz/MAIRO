|---|---|---|---|
| Home | 4.10 s → 3.58 s | 168 → 178 ms | 0 |

| Free first ad (`/preview`) | 3.92 s → 3.63 s | 111 → 117 ms | 0 |

Live production before (mobile lab): home LCP 3.18 s, TBT 216 ms, score 89.

**Changes**
- The headline is painted immediately (no masked entrance).
- The WebGL field starts after load, when the browser is idle.
- The label font is no longer preloaded.

With WebGL disabled, home TBT drops to 76 ms. Headless Chrome renders WebGL in software, so this overstates the cost on real phones.

Lab LCP is still above 2.5 s under this throttling. Field data (real users' 75th percentile) isn't collected yet. Turn on Vercel Speed Insights to measure it.
